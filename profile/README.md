The Canary programming language: [canary](https://github.com/canarylang/canary), the compiler `cyc`
and the package manager `flock`, in Rust. A general-purpose language for scripts, tools, services and
applications, whose whole job is to catch trouble before it ships. How we work:
[CONTRIBUTING](https://github.com/canarylang/.github/blob/master/CONTRIBUTING.md).
